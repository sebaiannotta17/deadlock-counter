# Deadlock Counter Guide

Guía rápida de counters para Deadlock (React + Vite + Tailwind). Los datos viven en `localStorage`.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Despliegue recomendado: [Vercel](https://vercel.com) con preset Vite (este repo incluye `vercel.json`).
